# RaceDay API - Part 2

Welcome to the **RaceDay** Web API project. This application provides a full-featured backend RESTful service for managing sports events, user authentications, registrations, participant details, event routes, categories, weather conditions, and race results.

---

## 🚀 Setup and Run Instructions

Follow these steps to run the RaceDay API locally on your machine:

### Prerequisites
* [.NET 8.0 SDK](https://dotnet.microsoft.com/download) (or .NET 7.0/6.0 depending on your environment)
* [Visual Studio 2022](https://visualstudio.microsoft.com/) with **ASP.NET and web development** workload
* SQL Server (LocalDB or Express)
